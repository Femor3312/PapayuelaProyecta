PAPAYUELA SMART - Software de gestión agronómica

Inicio rápido:
1. Descomprima la carpeta completa.
2. Abra index.html con Chrome o Edge, o ejecute INICIAR_SOFTWARE.bat.
3. El software funciona de forma local/offline y guarda sus registros en el navegador.

Novedad de esta versión:
- Interfaz amarilla y banner visual de papayuela.
- Módulo 7: Agente inteligente de recomendaciones.
- El agente analiza tratamiento, esquema de fertilización, peso de fruto, frutos, flores, altura y área foliar.
- Genera recomendaciones comparativas basadas en los datos históricos cargados.

Importante: el agente es un motor de apoyo a la decisión basado en los datos suministrados; no reemplaza el análisis de suelo ni la asesoría profesional agronómica.
